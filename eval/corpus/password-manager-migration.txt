Moving to a new password manager

1. Export the old vault to an encrypted file (or CSV only on an offline machine, deleted right after import).
2. Import into the new manager and spot-check logins with attachments, notes and custom fields, which often do not survive.
3. Move two-factor authentication: authenticator seeds are not part of most exports. Re-enrol each account and save new recovery codes.
4. Print the emergency kit with the master password hint and secret key, and keep it with other important papers.
5. Delete the old vault only after a month without problems.
